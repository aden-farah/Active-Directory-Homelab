# Active Directory & Entra ID Homelab

This repository is where I document my journey learning **Active Directory, Windows Server, networking, and Microsoft Entra ID** through HomeLab and hands-on practice.

I started this homelab to get a better understanding of how identity and access management works in real environments, instead of only learning the theory.

## What I'm learning

The plan is to work through topics such as:

* Active Directory Domain Services
* Users, groups, and Organizational Units (OUs)
* Group Policy
* DNS and DHCP
* Domain-joined Windows clients
* File servers and permissions
* Authentication and access control
* Microsoft Entra ID
* Hybrid identity and how on-premises AD connects with cloud identity

## Current Lab

The lab currently includes:

* **DC01** – Windows Server 2022 Domain Controller
* **CLIENT01** – Windows 11 domain-joined client
* **FS01** – Windows Server file server
* Domain: `adlab.local`

I have already worked with creating users and OUs, joining machines to the domain, Group Policy and basic file server configuration.

## Status

This is an ongoing learning project. I have paused the lab for now, but I plan to come back to it and continue documenting what I learn as I progress.

The main goal of this repository is to show the hands-on work behind my learning and build a stronger understanding of Microsoft identity and infrastructure.
